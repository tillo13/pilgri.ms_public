Trail Construction System

Crew-Built Trails for Expedition Speed — February 2026

Real Mars physics, incremental progress, always something to do

The Core Concept
"Expeditions lock vehicles for days. Crew sits idle. Give them something meaningful to do — build trails that make future expeditions faster."
— Design Session, Feb 1 2026

What We're Building

A trail construction system where your crew (Captain, Scientist, ARIA) builds trails toward explored landmarks in 5-10 minute sessions. Each session adds a tiny amount of trail (0.01-0.05 km), but it accumulates over days and weeks. Even partial trails boost expedition speed proportionally.

Key Principles:
  • Real Mars physics — Building speed based on actual EVA capabilities (~0.1-0.2 km/hour of trail work)
  • Incremental progress — Every 0.001 km helps. No thresholds, just continuous improvement
  • Proportional speed bonus — 10% of trail built = 5% speed bonus (linear scaling)
  • Crew returns to rest — Sessions are 5-15 min, then crew needs recovery (realistic, engaging)
  • Any explored direction — Build toward any landmark you've discovered via expeditions
  • Everyone contributes — Captain, Scientist, and ARIA can all work on same trail
Real Mars Physics

Trail building speed is based on actual human capabilities on Mars:

Mars EVA Constraints
Max EVA hours per sol 8 hours
Walking speed on Mars 2 km/h (from expedition_utils.py)
Trail BUILDING speed (10x slower than walking) 0.1-0.2 km/h base
Trail built per full EVA day 0.8-1.6 km

Why Building is Slower Than Walking

  • Placing navigation markers at regular intervals
  • Clearing rocks and debris from the path
  • Compacting regolith for stable footing
  • Documenting terrain for future reference
  • Setting up emergency shelter points

A 150 km trail would take ~100-200 EVA days to complete at base speed. With upgrades (Logistics, equipment, research), this can be reduced to 50-100 days. This is intentionally slow — trails are long-term investments.

Gameplay: 5-10 Minute Sessions

For engaging gameplay, we translate EVA work into micro-sessions:

Session Duration → Trail Progress
1 minute session +0.002-0.004 km (2-4 meters)
5 minute session +0.010-0.020 km (10-20 meters)
10 minute session +0.020-0.040 km (20-40 meters)
15 minute session (max) +0.030-0.060 km (30-60 meters)

Why this works: Expeditions take days (you check once/twice daily). Trail building takes minutes (you can do 5-10 sessions per visit). Always something to do, never stuck waiting.

All Three Working Together

Crew members can work on the same trail simultaneously. Their contributions stack:

  • Captain builds 0.015 km in 5 min session
  • Scientist builds 0.012 km in 5 min session
  • ARIA builds 0.018 km in 5 min session
  • Combined: 0.045 km per round (3× faster than solo)
ARIA's New Skills (visible on ARIA tab):
  • Resonance — Trail building efficiency (levels up with trail work)
  • Crystal Sensing — Reduces terrain penalties on trails
  • Lore Memory — Increases lore fragment discovery chance

ARIA is NOT instant. She takes 5-10 min like the others (she's a 4D printer, not magic).

🛠️ Expanded Trail Modifiers (V2 Enhancement)

Beyond the base stat bonuses (Logistics, Navigation, Resonance), trail building speed can be enhanced by multiple game systems. This encourages upgrading across the board and creates satisfying stat-stacking gameplay.

Final Speed Formula

Combined Build Speed

Proportional Speed Bonus

Unlike the old threshold system (none→marked→cached→highway), the new system is continuous:

Speed Bonus Formula
trail_speed_mult = 1.0 + (km_built / total_distance) × 0.5

Max bonus is +50% speed when trail is 100% complete

Example: 150 km Trail to Jezero Crater

Trail BuiltPercentageSpeed BonusExpedition Time Impact
0 km0%1.00×Base speed
0.5 km0.3%1.002×Barely noticeable, but real!
15 km10%1.05×5% faster
45 km30%1.15×15% faster
75 km50%1.25×25% faster
150 km (complete)100%1.50×50% faster!

Key insight: Even 0.001 km of trail helps. 1.0 + (0.001 / 150) × 0.5 = 1.0000033× — tiny, but it accumulates session after session.

Key Design Clarifications
VISITED SITES, not landmarks:

You can only build trails to places you've actually visited via completed expeditions. Not just "discovered" landmarks - actually BEEN there. This makes trail building a reward for exploration.

NO distance limits:

Any visited site can have a trail built, regardless of distance. If you've been there, you can chart a trail to it. The map shows ALL visited sites.

0.01-0.05 km per session is INTENTIONAL:

Slow progress is by design. Future upgrades (equipment, research, stats) will speed this up. The point is having SOMETHING meaningful to do when you log in - character progression through XP, not quickly finishing trails.

UI Flow: Click map → Choose crew member:

Similar to expeditions where you pick a vehicle, clicking a visited site on the map opens a "Chart Trail" modal showing all 3 crew members (Captain, Scientist, ARIA) with their stats, costs, and build rates. Pick one to send.
