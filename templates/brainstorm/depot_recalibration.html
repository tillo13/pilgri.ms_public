Depot Recalibration

Building Upgrades Need to Matter More — New Systems, New Purpose

April 2026 — Bug #1270 (P1) + Bug #1271 (Rebalance Costs, P1)

The Problem — Depot Needs Recalibration

From Bug #1270 (Luke): "Depot needs to be recalibrated to incorporate past few months of game features."

The Depot was designed before Signal detection, trail building, Robot construction, and stat progression existed. Buildings need new purposes tied to these systems. Right now, many upgrades feel like "number go up" without clear impact on gameplay.

Luke's specific callouts for what buildings should contribute to:

# Building Should Contribute To Current State
1 SV generation Some buildings do this already
2 Trail building speed Not connected at all
3 Faster building times (meta-upgrade) Nothing speeds up Depot builds
4 Crew member stats EVA Suit has bonuses but they're not applied (Bug #502)
5 Signal detection Not connected at all
Current Upgrade Categories — What Exists

Related bug: #1149 — Split Automation Drones into separate Maintenance Drone and Mining Drone upgrade paths. Currently one upgrade mashes together two unrelated things.
New Building Purposes — What Should Change

Each building category should connect to the new game systems. This is the core of the recalibration.

Building Current Purpose New Additional Purposes
Scanner Discovery rate Signal detection range bonus — higher level = wider detection radius. This is the primary Signal lever from buildings.
Generator Shard generation Powers robot operation — robot effectiveness limited by generator level. Also powers Signal decryption speed.
Lab / Research Unlocks tech ARIA progression trigger — Lab L3+ triggers ARIA Signal hints. Analysis speed for Signal fragments.
Automation Maintenance + mining Trail building speed bonus — drones help clear terrain. Robot construction speed assist.
EVA Suit Stat bonuses (not applied) Actually apply stat bonuses. Connect to captain stat effects once those are defined.
Rover / Vehicles Expedition range + speed Closest-approach detection benefits — faster vehicles cover more ground, more chances to pass near signals.
Bunker Storage Discovery storage for robot components — need space to store legendaries/rares while collecting for robot build.
Key questions:
  • Do we ADD effects to existing levels, or redesign the level progression?
  • Should new effects unlock at specific levels (e.g., Scanner gets Signal detection at L3+)?
  • Does this change the value proposition of early vs late upgrades?
Build Times & Speed — The #1 Pain Point

Bug #1265 (P1, Awaiting QA): "Is there currently any way to speed up buildings? If not, there should DEF be some way."

Currently there is NO way to speed up Depot build times. Once you start a build, you wait. No acceleration, no rush, no crew assignment, no Shard spend. This makes late-game upgrades (weeks to months) feel punishing.
Speed-Up Method How It Works Pros Cons
Shard Rush Spend Shards to reduce remaining time by X% Shard sink, player agency Pay-to-win feel if too powerful
Crew Assignment Assign scientist/robot to help build (faster with higher ENG stat) Ties into stats system, meaningful choice Crew unavailable for other tasks
Automation Drone Bonus Higher drone level = faster builds passively Makes Automation upgrades more valuable Passive, no player decision
Captain Logistics Stat Higher Logistics = faster builds across the board Stat matters, compounds over time Passive, no per-build decision
Combo: All of the above Stack passive bonuses + optional rush Multiple levers, rich gameplay Complexity, balance needed
Which approach does Luke prefer? Crew Assignment feels most aligned with his "stats matter" philosophy. Shard Rush adds player agency but risks "mobile game" feel. Automation Drone is the simplest to implement.
Cost Rebalancing — Bug #1271

From Bug #1271 (Luke, P1): "The cost of upgrades seem like they need a rebalance."

If buildings now do MORE (Signal detection, trail speed, robot support), their costs need to reflect the expanded value. Some may need to cost more (they're more powerful now), some may need to cost less (they were overpriced for what they did).
Questions for Luke:
  • Which specific upgrades feel too expensive for what they do?
  • Which feel too cheap (you'd buy them instantly)?
  • Should the curve be steeper (cheap early, very expensive late) or flatter?
  • Do new effects justify keeping current prices, or should prices change WITH the new effects?
  • Mars Realism: early tiers affordable (thousands), mid expensive (100k+), late massive (500k+) — does this still feel right?
Maintenance Drone — Multiple Related Bugs

Three bugs orbit the Maintenance Drone:

Bug Issue Status
#1266 Maintenance Drone doesn't do anything Awaiting QA
#1267 Maintenance Drone not in Depot or Upgradable ReOpen
#1149 Split Automation into Maintenance Drone + Mining Drone paths Backlog
#1161 Need Feature ideas for Drone Backlog
Design decision needed:
  • Option A: Split Automation into Maintenance + Mining. Two separate upgrade paths in Depot.
  • Option B: Keep Automation as-is. Maintenance Drone is a separate new building category.
  • Option C: Drone becomes the Robot's tool. Robot controls drones, upgrading the robot upgrades drone capability.
Option C ties nicely into the Robot Crew Member brainstorm — the robot manages your fleet of drones.
Upgrade Display — Show What Buildings Do

Related bugs: #1268 (Standardize multiplier format), #1269 (What does "unlocks research" mean?), #1274 (Depot cards showing placeholder icons)
