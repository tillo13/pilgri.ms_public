The Decoder Terminal & Eternal Ledger

The Decoder Terminal on /signal is the rabbit hole for curious players. It's a game-within-the-game built on top of the Sepolia blockchain. This does NOT conflict with the Origin Site hunt — it's a separate layer that rewards players who go deeper.

The Layers:
  1. Origin Sites — the main physical hunt (explore Mars, find sites by proximity)
  2. Decoder / Ledger — the ARG/meta layer (decode blockchain transactions, find hidden codes)
  3. Lost Signal Sites — the bridge (physical discovery tx_hashes unlock the final 3 sites)

How the Blockchain Works In-Game

What Every Transaction Contains

Every shard transfer writes to Sepolia with a data field containing:

  • A base message describing the action (purchase, reward, income, etc.)
  • A real Mars mission quote from pilgrim.mars_mission_messages (208 quotes), appended by append_cryptic_mars_message()

Origin Site claims embed a special signature:
ORIGIN://CURIOSITY//FOUNDER:Andy//SIG:0xWallet//SOL:142

Decoder Terminal Flow (IMPLEMENTED)
  1. Player pastes a 0x... transaction hash into the Decoder on /signal
  2. 3-phase animation: SCANNING LEDGER → EXTRACTING DATA → DECODING
  3. Backend fetches tx from Sepolia, decodes hex data field to plaintext
  4. Shows both the raw hex input data AND the decoded message
  5. ARIA's orb pops open with a curious reaction — encourages more exploration
  6. No Etherscan links shown — players must figure out the blockchain connection themselves
What Players See When Decoding Different Tx Types

Regular tx (purchase, income): Status "LEDGER ENTRY FOUND" — decoded message shows action + Mars mission quote. ARIA reacts with curiosity.

Origin claim tx: Status "ORIGIN ECHO DETECTED" (gold) — shows the ORIGIN:// signature with founder name. ARIA reacts with awe.

ARIA bond fragment: Triggers the full EpicReveal cinematic — already implemented.

Hidden signal tx (future): If decoded data contains SIGNAL://UNLOCK:CODE, extracts the code and matches against signal_puzzles table → puzzle solved, legendary reward.

Signal Puzzles — Built But Not Wired

Current State (March 2026): The puzzle infrastructure exists but has gaps:
  • pilgrim.signal_puzzles table exists — 1 puzzle seeded: "The Answer" (code: HITCHHIKER, the 42 easter egg, max 10 solvers, 0 solved)
  • decode_signal_puzzle() function exists in signal_utils.py — validates codes, records solvers, awards legendary items
  • NO route calls it — the function is dead code, no API endpoint wired up
  • NO transactions embed SIGNAL://UNLOCK:CODE — nothing to find yet
  • The Decoder frontend only accepts 0x... format — you can't type "hitchhiker" directly
  • The decoder checks for SIGNAL://UNLOCK:CODE in decoded tx data — but since no tx has one, it never triggers
To Complete This System, We Need
  1. Embed SIGNAL://UNLOCK:HITCHHIKER into specific transactions (e.g., certain shard payouts, milestone rewards)
  2. Decide: should players ALSO be able to type codes directly (not just via tx decode)?
  3. Seed more puzzles beyond HITCHHIKER — maybe one per origin site region?
  4. Wire up rewards — decode_signal_puzzle() returns reward_prompt but nothing generates the item yet

The Three Lost Signal Sites — The Bridge

3 of the 14 Origin Sites are special — Mars-3, Beagle-2, and Schiaparelli. These are real missions that never transmitted usable data. In real life, they went silent. In-game, their signals are "fragmented" — they can't be detected by normal proximity sensors.

KEY DESIGN DECISION — Luke needs to weigh in:

Should these 3 sites be findable by proximity like the other 11 (just harder — smaller radius, scanner upgrade required)? Or should they require the tx_hash unlock chain below?

Tradeoff: The tx_hash system is narratively cool but creates a dependency — nobody can complete all 14 until 11 other founders exist. With 2 active players right now, that could take a very long time. Proximity-based would let a dedicated solo player eventually find all 14.

Option A: Three-Act Unlock Chain (current brainstorm design)

Act 1 — First Voice (Mars-3)

The first origin site founder's tx_hash unlocks Mars-3. The earliest explorer opens the door. Mars-3 was the first spacecraft to soft-land on Mars (1971, USSR) — it transmitted 14.5 seconds of data, then silence. The first founder echoes that first voice.

Act 2 — Last Voice (Schiaparelli)

All 11 normal origin sites must be claimed first. The last founder's tx_hash unlocks Schiaparelli. The circle closes. Schiaparelli (2016, ESA) crashed at 300 km/h — its computer thought it had already landed. The last founder completes the main sequence.

Act 3 — ARIA Remembers (Beagle-2)

A captain gives ARIA both tx hashes in chat. She tells the story of Beagle-2 — the lander she "watched" for 12 years, intact on the surface but unable to call home. Found by satellite in 2015, a Christmas gift that never opened. She generates the final unlock code. This is the tearjerker moment of the entire game.

Option B: Proximity-Based (simpler)

Harder to Detect, Not Impossible
  • All 14 sites findable by proximity — no dependency on other players
  • Lost Signal sites have smaller detection radius (20km instead of 42km)
  • Or require a scanner upgrade before they become detectable
  • Keep the lore: "these signals are fragmented, harder to read" — but still physically findable
  • The Three-Act narrative could still exist as an alternate path — not the only path
Current Implementation State:

  • unlock_code field exists but is empty — not set to any tx_hash
  • Map popup shows "LOST SIGNAL" with cryptic hint + code input field
  • /api/signal/lost/decode route exists — does simple string match against unlock_code
  • Nothing connects founder tx_hashes to unlock codes — Three-Act is brainstorm-only
