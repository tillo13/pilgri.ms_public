Per-Expedition Path Detection — The Math

The single biggest improvement: switch from destination-only to path-proximity checking. The function already exists.

Current vs Proposed Detection
Current check_origin_site_proximity(dest_lat, dest_lon) — checks ONE point
Proposed point_to_path_distance(site, base, dest) — checks ENTIRE route
Function location mars_math.py:point_to_path_distance() — already exists, used for mission artifact filtering
How It Works:

When an expedition completes, instead of just checking distance(destination, origin_site), we check min_distance(expedition_path, origin_site). A 500km expedition creates a 500km-long detection corridor. If the path passes within 42km of a site at any point, that's a detection — even if the destination is 300km away.

Performance: 14 sites x 1 path calc per expedition = 14 calls. Negligible cost.

Concrete example: Luke's expedition #47 went to Hyblaeus Dorsa (destination 599km from InSight). But the path from his base may have passed within 200km of InSight. With path detection, that expedition would have triggered a "Strange Readings" hint instead of nothing.

Visitor Tier Rewards — What You Get For Finding a Site
IMPLEMENTED (March 2026) — Full 5-tier visitor reward system live in signal_utils.py. Every visitor to an Origin Site receives a unique Flux-generated item based on their arrival rank.

The Founder gets the legendary item, but every visitor after gets something too — scaled by how early they arrived. This creates ongoing incentive to visit claimed sites, not just hunt unclaimed ones.

Rank Tier Item Awarded Rarity
1st Founder Custom legendary artifact with captain name engraved on-chain Legendary
2nd-3rd Early Witness Witness Shard: {mission} Rare
4th-10th Pioneer Pioneer Fragment: {mission} Uncommon
11th-42nd Pilgrim Pilgrim Stone: {mission} Common
43rd+ Wanderer Wanderer's Mark: {mission} Common

How It Works

  • Every visitor gets a unique Flux-generated image with their captain name + wallet engraved
  • Every visit writes a Sepolia blockchain transaction: ORIGIN_VISIT #N | {mission} | {captain} | {wallet}
  • Rank 42 gets a special blockchain message: "You found the answer" (Hitchhiker's Guide easter egg)
  • No visitor cap — rank 43+ continues as Wanderer tier indefinitely
  • Items stored in GCS (origin_visitor_rewards/) and linked to player inventory via replicate_assets
